SDK 安装包验收

此目录保留旧自动验收夹具，不随SDK发布。持续交互与TS/JS消费已迁入 E:\0-SpringGISNet，请在独立应用打开 /sdk.html 或 /sdk-js.html。

这是自动验收页面，不是持续展示的业务地图。它使用自造瓦片、DEM、MVT，完成后会销毁地图以验证资源释放；地图区域变空且显示 PASS 是正常结果。

引擎根目录 npm run test:sdk 现在只检查dist库输出。日常交互请在独立应用运行 npm run dev 或 npm run preview，不再由引擎启动临时消费者。

不能用 Live Server 直接打开这里的 TypeScript 源码入口。只有 npm run build 生成的 dist/index.html 才能交给静态服务器。详细步骤见仓库根目录的 SDK使用说明.md。
